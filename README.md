# AI-Doctor

AI-Doctor is a Flask-based application designed to provide medical diagnosis and recommendations using AI.

## Features

- **Medical Diagnosis:** Analyze symptoms and provide potential diagnoses.
- **Recommendations:** Offer treatment suggestions and preventive measures.
- **User-Friendly Interface:** Easy to use and navigate.

## Technologies Used

- **Python:** Core programming language.
- **Flask:** Web framework.
- **HTML/CSS:** Frontend design.
- **Machine Learning Libraries:** Scikit-learn, TensorFlow.
